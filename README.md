# CASPR++

**Jouw schooldag, jouw stijl.**

CASPR++ geeft CASPR een persoonlijker uiterlijk en brengt handige schoolwidgets
en chat samen. Het project bestaat uit een browserextensie voor Chrome en Edge
en een aparte backend voor accounts en communityfuncties.

**CASPR++ is uitsluitend bedoeld voor leerlingen van de Broederschool.**
De extensie en de gekoppelde diensten zijn afgestemd op de CASPR omgeving van
die school.

## Wat kun je ermee?

- **Maak CASPR persoonlijk.** Kies een thema, pas het glaseffect aan en geef je
  dashboard een eigen uitstraling.
- **Houd overzicht.** Gebruik widgets voor je rooster, punten, volgende les en
  een focustimer.
- **Praat met medeleerlingen.** Gebruik globale chat, klaschat en privéberichten,
  met reacties, antwoorden en GIFs.
- **Werk samen.** Maak privégroepen, verdeel taken en gebruik polls en
  vastgezette berichten.

## Onze repositories

| Project | Wat vind je er? | Technologie |
| --- | --- | --- |
| **Extensie** | Thema’s, dashboardwidgets, instellingen en de chatinterface. | TypeScript, HTML en CSS |
| **Backend** | Accounts, berichten, groepen, meldingen en moderatie. | Node.js, Express, Socket.IO en SQLite |

De repositories worden apart beheerd. In de README van elk project vind je de
installatiestappen, configuratie en uitleg voor ontwikkelaars.

## Aan de slag

Open de extensierepository en volg de installatie-instructies. Wil je zelf een
server draaien? Gebruik dan de README van de backendrepository en configureer
de extensie voor jouw backendadres.
 
## Meebouwen

Een fout gevonden of een idee voor een verbetering? Open een issue in de
betreffende repository. Beschrijf wat je verwachtte, wat er gebeurde en hoe we
het kunnen reproduceren. Pull requests zijn welkom.

Gebruik bij screenshots en voorbeelden fictieve gegevens. Deel geen
wachtwoorden, API-sleutels, privégesprekken of persoonsgegevens van leerlingen.

## Over het project

CASPR++ is een onafhankelijk communityproject en geen officiële CASPR-uitgave.
De licentie en eventuele aanvullende informatie staan in de afzonderlijke
repositories.
